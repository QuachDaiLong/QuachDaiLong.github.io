# Quách Đại Long — Modern 3D Artist Portfolio

Portfolio website HTML/CSS/JS, thiết kế theo hướng modern editorial / 3D artist.

## Chạy bằng VS Code

1. Giải nén project.
2. Mở folder bằng Visual Studio Code.
3. Thay các ảnh trong `assets/`.
4. Mở `index.html` bằng trình duyệt.

Có thể cài extension **Live Server** trong VS Code:
Right click `index.html` → Open with Live Server.

## Ảnh cần thay

- `hero.jpg` — ảnh/render chính ở Hero.
- `profile.jpg` — ảnh cá nhân.
- `project-elf.jpg` — project 01.
- `project-study.jpg` — project 02.
- `project-process.jpg` — project 03.

Sửa trực tiếp trong `index.html`.
